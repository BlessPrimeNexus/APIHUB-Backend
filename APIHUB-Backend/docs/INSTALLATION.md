# Installation
1. Backend (`docs/DEPLOYMENT.md`), verify with `curl https://<domain>/health`.
2. Build and install the APK (`docs/ANDROID_BUILD.md`).
3. Open APIHUB → **Connect to a server** (or *Continue offline*) → create the first account → Projects → New → API Builder → add endpoints → Publish.
4. Optional: after creating your account set `ALLOW_REGISTRATION=0` and restart.
